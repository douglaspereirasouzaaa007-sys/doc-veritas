# Document Verifier Pro

preciso criar um sistema que uma empresa me contratou para isso, eles querem que eu melhore o sistema deles, esse sistema será uma verificadora de documentos como atestados, receitas e laudos, deve ter um painel do dono, esse sistema deve ter uma api para eu conectar com outro sistema, e esse sistema vai gerar os qr codes e as paginas profissionais, cada pagina deve ter os dados do paciente, nome, data de nascimento, cpf, e os dados do estabelecimento, endereço e o nome, data e horario de emissão, e os dados do documento, se for atestado deve conter o dia de inicio e o dia de termino a quantidade de dias de afastamento, tudo deve estar em formato brasileiro, datas formato brasileiro e etc, deve mostrar o texto do documento que a api retorna e etc, enfim faça tudo perfeito, faça identico a memed, veja as imagens e faça identico as paginas, apenas copie, use as imagens, faça tudo perfeito !, painel do dono deve dar para gerenciar tudo, ver as paginas geradas, poder editar e etc, deve ter a documentação api completa e explicando no painel do dono, e tudo deve funcionar
